# Console

Console is a terminal application that works in your terminal. It's based on the [tui](https://github.com/php-tui/php-tui) php ui terminal library, which provides a simple interface with agentic tooling and chat bot. It's designed to be used in conjunction with other tools and applications to provide a seamless experience for your users.

### Installation

You can install Console using Composer:

```bash
git clone https://github.com/purencool/console.git
cd console
cp .env.example .env
composer install
bash ./app.sh
```
